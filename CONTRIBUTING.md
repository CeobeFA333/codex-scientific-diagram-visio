# Contributing

Focused issues and pull requests are welcome.

Before submitting a change:

1. Keep scientific correctness and editability requirements explicit.
2. Do not commit private manuscripts, datasets, credentials, personal paths, or copyrighted example figures without permission.
3. Keep each skill's YAML frontmatter limited to `name` and `description`.
4. Put detailed guidance in `references/` and deterministic utilities in `scripts/`.
5. Run `python scripts/validate_release.py`.
6. Run the changed workflow on a synthetic or openly licensed example.

Bug reports should include the operating system, Visio version, Codex surface, source artifact type, expected behavior, and a redacted screenshot when relevant.

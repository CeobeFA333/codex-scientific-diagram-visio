# Privacy Policy

Effective date: 2026-09-08

Codex Scientific Diagram Visio is an open-source, skills-only plugin. The packaged plugin does not operate a server, create user accounts, collect analytics, or transmit files to the publisher.

The skills may instruct the user's agent to read files explicitly placed in scope, control Microsoft Visio or Adobe Illustrator, create local work files, and optionally invoke image-generation capabilities already available in the user's environment. Inputs can include manuscripts, PDFs, images, source-data tables, SVG/AI/VSDX files, and model code. The packaged plugin does not upload these materials or generated outputs to the publisher. Any data handling by Codex, ChatGPT, Microsoft products, Adobe products, GitHub, or an image-generation provider is governed by the terms and privacy settings of those services.

Users should not place confidential manuscripts, proprietary source code, personal data, credentials, datasets, or model weights into public examples or issue reports. Work files remain in locations selected by the user unless the user explicitly authorizes another action.

Privacy questions can be submitted through the repository's GitHub Issues without including sensitive information.

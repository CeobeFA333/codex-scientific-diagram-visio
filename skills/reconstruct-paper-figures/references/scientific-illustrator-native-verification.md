# Scientific Illustrator native verification

Use this gate when a normal `.drawio` candidate needs to be promoted from
structural compatibility to a Scientific Illustrator runtime result. Do not use a
plain XML audit, a draw.io web preview, or a PowerPoint/Visio run as substitute
evidence.

## Current local baseline

As checked on 2026-08-26, Scientific Illustrator and draw.io Desktop are not
installed in this workspace. Node.js, Git, Codex plugin commands, Python with
`python-pptx`, and the FIG07 `.drawio` candidate are available. Therefore the
current truthful status is `structural-candidate-runtime-not-invoked`.

The upstream project integrates PowerPoint/WPS and draw.io backends. A
pre-generated `.drawio` file opened by the plugin can prove native compatibility,
but it was not generated by Scientific Illustrator unless the live API created the
objects from a blank canvas.

## Minimum compatibility run

1. Install the official plugin and draw.io Desktop only after authorization; record
   plugin, server, application, Node.js, and operating-system versions.
2. Copy the candidate to a new non-overwriting round-trip filename and bind both
   files by SHA-256.
3. Launch the copy through `drawio_live_launch` and require `connected=true`.
4. Inspect at least one stable semantic cell ID plus representative text, group,
   edge, and page-background cells.
5. Make one unmistakable test edit to a declared cell ID and record its before and
   after values. Never use a silent no-op as edit evidence.
6. Capture a screenshot, run the live figure audit, and save a new edited snapshot.
7. Export PNG, SVG, and PDF through the backend; bind each export by SHA-256.
8. Close the live session with confirmation, relaunch the edited file, and inspect
   the same cell ID to prove persistence.
9. Record `native_opened`, `native_edited`, `native_saved`, `native_exported`, and
   `native_reopened` separately. Keep
   `scene_generated_by_scientific_illustrator=false` for imported candidates.
10. Treat the backend exports as authoring evidence. Final publication still needs
    Illustrator Type/path inspection and an editable PDF audit.
